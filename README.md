# SpeedTest CLI — замер скорости интернета на Python

Консольная утилита на чистом Python для измерения реальной скорости загрузки данных и среднего времени отклика по HTTP/HTTPS.

Скрипт принимает URL ресурса (например, тяжёлую картинку или тестовый бинарный файл), выполняет к нему 10 последовательных запросов, дожидается полного скачивания каждого ответа и выводит итоговую статистику.

---

## Особенности реализации

- **Без сторонних зависимостей**: работает исключительно на стандартной библиотеке Python (`urllib.request`, `argparse`, `time`, `dataclasses`). Не требует выполнения `pip install`.
- **Потоковая загрузка**: тело ответа вычитывается чанками по 64 КБ, благодаря чему память не перегружается даже при загрузке файлов размером в сотни мегабайт.
- **Точные замеры**: время каждого запроса фиксируется с помощью монотонного таймера высокого разрешения `time.perf_counter()`.
- **Подавление кэша (`--no-cache`)**: опциональный режим с заголовками `Cache-Control: no-cache` и уникальным временным query-параметром для предотвращения получения закэшированных ответов от CDN и промежуточных прокси.
- **Удобный и приятный вывод**: информативная таблица каждого запроса и понятный итоговый блок.

---

## Единицы измерения скорости

В консоли и отчётах выводятся следующие величины:

1. **MB/s (МБ/с, Мегабайты в секунду)** — десятичные единицы ($10^6$ байт/с):
   $$\text{MB/s} = \frac{\text{Общий объём (байт)}}{\text{Суммарное время (с)} \times 1\,000\,000}$$
   Удобно для сопоставления с размером скачиваемых пользовательских файлов.

2. **Mbps (Мбит/с, Мегабиты в секунду)** — общепринятый сетевой стандарт ($10^6$ бит/с, где 1 байт = 8 бит):
   $$\text{Mbps} = \frac{\text{Общий объём (байт)} \times 8}{\text{Суммарное время (с)} \times 1\,000\,000}$$
   Именно в этих единицах интернет-провайдеры указывают тарифную скорость подключения.

3. **MiB/s (МиБ/с, Мебибайты в секунду)** — двоичные единицы ($2^{20} = 1\,048\,576$ байт/с).

---

## Методика расчёта

- **Время одного запроса ($T_i$)**: интервал от начала отправки HTTP-запроса до вычитки последнего байта ответа.
- **Среднее время запроса**:
  $$\bar{T} = \frac{1}{N} \sum_{i=1}^{N} T_i$$
- **Общий объём скачанных данных ($V$)**:
  $$V = \sum_{i=1}^{N} \text{bytes}_i$$
- **Итоговая скорость скачивания**:
  $$\text{Speed} = \frac{V}{\sum_{i=1}^{N} T_i}$$

## Требования и запуск

### Требования
- Python 3.8 или выше.
- Дополнительные библиотеки устанавливать не нужно.

### Примеры запуска

1. **Базовый запуск (10 последовательных запросов по умолчанию):**
   ```bash
   python speedtest.py https://speed.cloudflare.com/__down?bytes=10000000
   ```

2. **Интерактивный ввод адреса (если запустить без параметров):**
   ```bash
   python speedtest.py
   # Скрипт вежливо запросит: "Введите адрес (URL) для проверки скорости:"
   ```

3. **Запуск с флагом адреса и другим количеством запросов:**
   ```bash
   python speedtest.py -u https://example.com/image.jpg -n 10
   ```

4. **Запуск с отключением кэширования:**
   ```bash
   python speedtest.py https://example.com/image.jpg --no-cache
   ```

5. **Вывод результата в формате JSON (для интеграций и скриптов):**
   ```bash
   python speedtest.py https://example.com/image.jpg --json
   ```

6. **Справка по всем доступным флагам:**
   ```bash
   python speedtest.py --help
   ```
